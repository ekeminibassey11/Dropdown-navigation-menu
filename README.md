- View the relevant dropdown menus on desktop and mobile when interacting with the navigation links
- View the optimal layout for the content depending on their device's screen size
- See hover states for all interactive elements on the page

### What I learned

I learned how to make a page mobile-first, how to toggle different classes using JS. This was a huge achievement for me because i only just started learning about JS. Another thing I learned was the use of certain features when styling the page using Tailwind CSS.

For future projects, I would like the dropdown menu to actually have real destinations for Careers, About, Login, and Register instead of in-page anchors.
